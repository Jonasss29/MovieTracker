## Deutsch

Persönlicher Tracker für Filme und Serien: Was schaue ich gerade, was will ich schauen, was habe ich gesehen – mit Fortschritt, Bewertung, Tags, Notizen und Links.

> **Status:** in Entwicklung, noch kein Release.

**Grundsätze**
- **Portabel:** läuft ohne Installation aus einem Ordner (z. B. USB-Stick) und schreibt nur in diesen Ordner.
- **Privat:** kein Netzwerkzugriff ohne ausdrückliche Aktion, keine Telemetrie, optional verschlüsselte Datenbank.
- **Plattformen:** Windows und Linux, Android vielleicht später.

Gebaut mit Flutter. Planung und Sicherheitskonzept: [docs/PLAN.md](docs/PLAN.md), [docs/SECURITY-CONCEPT.md](docs/SECURITY-CONCEPT.md) (auf Deutsch).

## English

Personal tracker for movies and series: what I'm watching, what I want to watch, what I've seen – with progress, rating, tags, notes and links.

> **Status:** in development, no release yet.

**Principles**
- **Portable:** runs from a folder (e.g. a USB stick) without installation and writes only to that folder.
- **Private:** no network access without explicit user action, no telemetry, optionally encrypted database.
- **Platforms:** Windows and Linux, maybe Android later.

Built with Flutter. Planning and security concept: [docs/PLAN.md](docs/PLAN.md), [docs/SECURITY-CONCEPT.md](docs/SECURITY-CONCEPT.md) (in German).
